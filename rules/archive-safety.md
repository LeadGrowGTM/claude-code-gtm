# Archive & Safety Rules

## Archive Policy

- NEVER use `rm`, `del`, or delete commands
- If deletion requested: Move to `archive/` with date prefix
- Always backup before significant changes

## MCP Safety Rules

**NEVER use:**

- Any delete/remove/archive operations
- Force operations

**ALWAYS:**

- Pause instead of delete
- Duplicate instead of overwrite
- Confirm destructive actions with user
